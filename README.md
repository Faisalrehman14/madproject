# SpendWise: Personal Expense Tracker

SpendWise is a mobile application designed to help university students and young professionals track their daily expenses effortlessly.

## Project Overview
This project is part of the Mobile Application Development (CS02310) Lab Task 1. The goal was to create the UI and layouts for the core features of the app using Kotlin and Android Studio.

## Features (Task 1)
- **Dashboard**: View total balance and recent expenses.
- **Add Expense**: Form to enter amount, category, date, and notes with validation.
- **Expense List**: Scrollable list of all recorded expenses with an empty-state design.
- **Expense Details**: View details of a specific expense with edit and delete options.
- **Monthly Summary**: Per-category breakdown of monthly spending.

## Tech Stack
- **Language**: Kotlin
- **Layouts**: ConstraintLayout, ScrollView
- **Components**: Material Components, RecyclerView
- **Architecture**: Multiple Activities with Intent-based navigation.

## How to Run
1. Open the project in **Android Studio**.
2. Sync the project with Gradle files.
3. Run the app on an **Emulator** or a physical device.
4. The app supports both **Portrait** and **Landscape** modes.

## Known Limitations
- Data is static and not persisted across restarts.
- No database integration (planned for future tasks).
- No user authentication or advanced charts.
